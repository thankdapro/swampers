Mod Application

We’re recruiting server moderators for the swamp — three additional helpers to keep the Discord a safe space for fellow Swampers. Guidelines will be set with the royal advisory once mods are selected.

What does this mean? +

We will have three additional helps who keep the Discord a safe space for us Swampers. We’ll establish guidelines that the royal advisory and the Discord mods will follow after they get selected.

What if I’m running for a different position? +

For now we don’t have a set answer — mostly because we don’t have a set overlap yet. Should the question arise, we’ll discuss it with the affected positions. We’ll be prioritizing applicants who are not running for or holding other positions, but that doesn’t mean you shouldn’t apply. If you’re uniquely qualified (or better suited than others), you still have a good chance.

Do I need experience? +

Preferred, but not required — we need all hands on deck. What you don’t know or aren’t familiar with can be taught. So apply if you feel like contributing to the swamp!
